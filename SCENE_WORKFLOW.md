# Parallaxia — Agent 2.5D Scene Production Playbook

Этот файл создан для быстрой, стабильной и безошибочной работы с **любыми новыми изображениями** в будущих сессиях (без зависимости от внешних runtime API-вызовов).

---

## Как добавить новую 2.5D-сцену за 4 шага (без правки TypeScript-кода!)

Студия автоматически подхватывает все JSON-манифесты из папки `src/scenes/*.json` через `import.meta.glob`.

### Шаг 1. Подготовь и визуально изучи изображение
1. Помести исходное изображение в `src/assets/images/<slug>.jpg` (или `.png` / `.webp`).
2. Просмотри изображение (`view_file`) и разбей его мысленно на 3–9 зон в нормализованных координатах `x ∈ [0..1]` (слева направо), `y ∈ [0..1]` (сверху вниз):
   - **Дальний фон (`depth: 0.06–0.22`)**: небо, вид за окном, горизонт, дальние здания.
   - **Непрерывные наклонные плоскости (пол, стол, дорога, стена)**: обязательно задавай `depth` (верхний край) + `depthBottom` (нижний край, ближе к камере) — это полностью исключает «ступеньки» и разрыв полов!
   - **Средний план (`depth: 0.35–0.65`)**: мебель, мосты, деревья, архитектура.
   - **Передний план (`depth: 0.78–0.96`)**: главный герой, ваза, ветки, фонарь, ближний стол.

### Шаг 2. *(Опционально — максимальное кино-качество без артефактов)* Сделай Clean Plate и/или внешнюю карту глубины
Для сложных сцен с крупным вынесенным объектом перед структурированным фоном (книги, окна, кирпич, люди):
- **HD Clean Plate (`cleanPlateUrl`)**: сгенерируй копию того же кадра с удалённым объектом переднего плана (image-to-image через `generate_image` с `ImagePaths: ["/src/assets/images/<slug>.jpg"]` и промптом сохранить камеру/освещение/фон 1:1, но полностью удалить объект переднего плана и восстановить фон за ним). Укажи `"cleanPlateUrl": "/src/assets/images/<slug>_clean_plate.jpg"` в манифесте! Студия автоматически подставит чёткие HD-пиксели чистого фона в зоны дисокклюзии вместо диффузии.
- **Внешняя карта глубины (`depthMapUrl`)**: если есть готовая Ч/Б карта глубины (белый = ближе, чёрный = дальше), укажи `"depthMapUrl": "/src/assets/images/<slug>_depth.png"` — 3-канальный RGB Guided Filter автоматически привяжет её края к контурам фото.

### Шаг 3. Создай один JSON-файл `src/scenes/<NN>-<slug>.json`
Пример структуры с полным набором универсальных инструментов:

```json
{
  "id": "my-scene",
  "order": 5,
  "title": "Название сцены",
  "category": "Жанр · 3 плана",
  "imageUrl": "/src/assets/images/my_scene.jpg",
  "cleanPlateUrl": "/src/assets/images/my_scene_clean_plate.jpg",
  "aspectRatio": 1.7777777778,
  "defaultMotion": "orbit",
  "defaultAtmosphere": "dust",
  "defaultConvergence": 0.55,
  "defaultForegroundCut": 0.72,
  "defaultMidgroundCut": 0.35,
  "cinematographyNote": "Короткое описание глубины и движения камеры.",
  "blueprint": {
    "horizonY": 0.44,
    "groundSlope": 0.4,
    "edgeWeight": 0.06,
    "horizontalTilt": 0.0,
    "guidedRadius": 6,
    "guidedEps": 0.004,
    "regions": [
      {
        "label": "Фоновое окно / небо",
        "layer": "background",
        "shape": "polygon",
        "cx": 0.5,
        "cy": 0.2,
        "rx": 0.5,
        "ry": 0.2,
        "points": [[0.0, 0.0], [1.0, 0.0], [1.0, 0.4], [0.0, 0.4]],
        "depth": 0.08,
        "depthBottom": 0.16,
        "softness": 0.05
      }
    ]
  }
}
```

### Шпаргалка по анти-артефактным фильтрам внутри `regions[]`
Порядок зон в `regions[]` важен: **от дальнего фона → к среднему → к переднему плану** (последующие зоны аккуратно перекрывают предыдущие).

| Поле | Когда применять | Пример |
|---|---|---|
| `shape: "polygon"` + `points` | Любые сложные архитектурные силуэты, столы, полы, стены | `[[0.1,0.7], [0.6,0.7], [0.5,1.0], [0.0,1.0]]` |
| `depthBottom` | Наклонные поверхности (пол, стол, дорога, уходящая стена) | `depth: 0.35, depthBottom: 0.85` |
| `horizontalTilt` (в `blueprint`) | Комнаты и фасады, снятые под углом (левая часть ближе правой) | `0.18` (или `-0.18` если правая ближе) |
| `lumaMax` | Тёмный силуэт (мольберт, ветки, фонарь) на фоне светлого окна/неба | `lumaMax: 0.42` |
| `lumaMin` | Яркий проём окна / светлое небо за тёмными переплётами | `lumaMin: 0.45` |
| `greenMin` | Зелёная листва перед тёмной стеной/шторой той же яркости | `greenMin: 0.012` |
| `colorTarget` + `colorTolerance` | Выделить объект **любого цвета** (красный клён, жёлтая куртка, синий неон) | `colorTarget: [210, 60, 45], colorTolerance: 0.28` |
| `invertColorTarget: true` | **Универсальный «хромакей фона»**: всё внутри полигона, КРОМЕ цвета фона/стены/неба | `colorTarget: [220, 225, 232], colorTolerance: 0.22, invertColorTarget: true` |
| `satMin` | Насыщенный цветной объект на сером/нейтральном фоне | `satMin: 0.35` |
| `autoSkyMatte: true` | Объекты под открытым небом/туманом (автоматически сравнивает центр объекта с его контуром) | `autoSkyMatte: true` |

## Шаг 4. Быстрая детерминированная проверка в браузере (URL-параметры)

Перезапусти dev-сервер после добавления JSON и открой готовые диагностические URL в Playwright:

1. **Проверка теплокарты глубины** (убедись, что нет ореолов, провалов внутри объектов и «дыр» на окнах):
   `http://localhost:3000/?scene=<slug>&tab=depth&overlay=heatmap`
2. **Проверка живого 2.5D Гибрида (POM + Inpaint / Clean Plate)**:
   `http://localhost:3000/?scene=<slug>&tab=scene&overlay=final&pipeline=pom`
3. **Проверка маски разрывов и заполненного фона**:
   `http://localhost:3000/?scene=<slug>&tab=layers&pipeline=pom`
4. **Проверка 3D-разбора слоёв**:
   `http://localhost:3000/?scene=<slug>&tab=layers&pipeline=exploded`

### Проверочный чек-лист без артефактов
- [ ] **Единый объём героев**: светлая и теневая стороны одного объекта (ваза, человек, скульптура) имеют одинаковую глубину — не используй `lumaMax` на объектах, у которых есть яркий блик!
- [ ] **Плавные полы и столы**: есть `depthBottom`, нет резкого шва между верхом и низом плоскости.
- [ ] **Нет ложного захвата фона**: за тонкими ветками, спицами, рамами мольберта виден фон (`lumaMax`, `greenMin` или `invertColorTarget`).
- [ ] **Порог `defaultForegroundCut`**: выставлен выше среднего плана (`~0.70–0.76`), чтобы в дисокклюзию попадали только действительно отрывающиеся объекты переднего плана.
- [ ] **Юнит-тесты проходят**: `npx --yes tsx --test src/engine/depthPipeline.test.ts` автоматически валидирует все файлы `src/scenes/*.json`!
